# P4RAGON

A high-performance Open Source Intelligence (OSINT) framework designed for rapid data correlation and geospatial analysis. P4RAGON provides a streamlined command-line interface for cross-platform intelligence gathering, social fingerprinting, and geospatial tracing.

## Architecture

The system is built on a modular engine-core-ui architecture:

- **Engines**: Specialized modules for search, social media, and geospatial processing.
- **Core**: Handles networking, configuration management, and session integrity.
- **UI**: A terminal-based interface using modern rendering libraries for clear data visualization.

## Configuration

Configuration is managed via `~/.p4ragon/config.json`. You can toggle proxy settings and adjust behavioral delays directly through the application settings menu.
