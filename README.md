<h1 align="center">P4RAGON</h1>

<p align="center">
  Terminal-first OSINT suite for public intelligence collection, correlation, reporting, and packaged encrypted deployment.
</p>

---

## Overview

P4RAGON is an interactive terminal OSINT toolkit built around a modular engine architecture. It combines public search, social username discovery, geospatial lookup, metadata extraction, email pattern generation, crypto wallet lookup, report exports, and local encrypted configuration.

It also includes private search, tor search, database search, leaks database search.

The application is designed for a fast keyboard-driven workflow using Rich and questionary, with async network engines and optional encrypted PyInstaller builds for deployment.

## Features

| Area | Capabilities |
| --- | --- |
| Social OSINT | Username footprint checks across configured public sites |
| Identity Search | Public search dorks for names and profile discovery |
| Email Intelligence | Corporate email pattern generation and optional SMTP probing |
| Geo OSINT | IPv4 geolocation, BSSID lookup, nearby POI discovery, map generation |
| Metadata | Image metadata extraction through ExifTool or Pillow fallback |
| Network Utilities | Ping, DNS lookup, and common TCP port checks |
| Crypto Intelligence | BTC/ETH wallet extraction and lookup helpers |
| Reporting | JSON, HTML, Markdown, CSV, PDF, and AI brief exports |
| Privacy Controls | Zero-trace mode for no database/cache/document writes |
| Packaging | Encrypted in-memory PyInstaller loader with tier patching |
